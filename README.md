# AgriToken
AgriToken project is a blockchain-based system designed to digitize and tokenize agricultural assets. Its main idea is to represent farm produce as digital tokens on Hedera Ledger Technology, allowing farmers, buyers, and investors to trade and verify ownership securely.

you can visit [AgriToken](https://agritoken.onrender.com/#home) to tokenized and invest in crops and farm produce.

##  Features
- **Farmer Registration:** Farmers create verified profiles linked to their Hedera wallet.
- **Yield Tokenization:** Tokenize crop yields using the Hedera Token Service (HTS).
- **Investment Marketplace:** Browse and invest in tokenized farm assets.
- **Automated Profit Distribution:** Distribute profits at harvest based on real market prices.
- **Portfolio Tracking:** Monitor ROI, portfolio value, and past investments.
- **Farm Rating System:** Community-driven ratings to promote trust and transparency.

##  Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Blockchain:** Hedera Hashgraph SDK (HTS + HCS)
- **Wallet Integration:** MetaMask
